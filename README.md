# Garnet_11.11 — лендинг стоматологии «Гарнет»

Конверсионный лендинг клиники «Гарнет» (Краснодар, ул. Бабушкина, 295) с калькулятором
All-on-4, виниров и имплантации. Опубликован через GitHub Pages на домене test-direct-ad.ru.

## Что внутри

| Папка | Что это |
|---|---|
| `index.html` | Однофайловая сборка лендинга. Все шрифты, картинки, логотипы и иконки встроены внутрь файла — страница открывается без интернета и без папки с ассетами. Это то, что отдаётся в GitHub Pages. |
| `thanks.html` | Однофайловая сборка страницы «Спасибо за заявку»: тот же дизайн-системный код, фото команды клиники и печать «Рассрочка 0%». Тоже отдаётся в GitHub Pages. |
| `assets/` | Исходные ассеты: логотип клиники, логотипы систем имплантатов, фото врачей, фото команды, фото сканера, площадки (2ГИС, ПроДокторов, Яндекс Карты), шрифты Montserrat. |
| `project/` | Исходники: разметка макета `design/home.html` и `design/thanks.html`, клиентский скрипт `landing.js`, Go-каркас с обработчиком формы, бриф и ТЗ. |

## Как пересобрать

Всё оформление лежит в одном файле `project/design/home.html`. После правки собирается
однофайловая версия, в которую ассеты встраиваются как data URI, — это и есть `index.html`.
Страница «Спасибо» собирается так же из `project/design/thanks.html` и кладётся в `thanks.html`.

Скрипт сборки и правила выкатки лежат в рабочей папке проекта, в сам репозиторий
однофайловый билдер не включён: итоговый `index.html` и так самодостаточен.

## Статус

Лендинг опубликован как рабочая страница. Калькулятор считает по позициям публичного
прайса клиники и показывает сумму выбранных позиций, а не цену «под ключ» — совместимость
и актуальность цен подтверждает клиника.

Форма заявки принимает имя, телефон, согласие и состав расчёта из калькулятора, но
автоматическая доставка заявок пока не подключена: страница честно сообщает об этом и
предлагает позвонить или написать в MAX. Юридические документы и согласия — в статусе
«до подключения», до публикации для рекламы их нужно подтвердить у заказчика.

Страница «Спасибо за заявку» опубликована на `test-direct-ad.ru/thanks.html`: она
показывает фото команды клиники, печать «Рассрочка 0%» и напоминает о бесплатной
первичной консультации. Переход на неё с формы пока не сделан — заявки не отправляются.
